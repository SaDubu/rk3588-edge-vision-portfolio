# Model files

학습 가중치와 변환된 모델은 데이터 권리, 파일 크기, 배포 조건을 분리하기 위해 이 포트폴리오에 포함하지 않는다.

코드 스냅샷은 RK3588 대상 RKNN 모델 경로를 참조한다. 실제 통합 시에는 다음 자산을 별도로 준비하고 각 모델의 클래스 순서를 `configs/classes.example.yaml`과 대응시켜야 한다.

- 학습 또는 확보한 원본 모델
- RKNN Toolkit으로 RK3588 대상 변환을 완료한 `*.rknn`
- 모델별 입력 크기, 정규화, 양자화 조건
- 클래스 순서와 후처리 임계값

모델을 이 저장소에 추가하지 않도록 `.gitignore`에서 주요 가중치 확장자를 제외했다.
