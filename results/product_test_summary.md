# 10개 상품 프레임 테스트 요약

최신 SMOF 저장소의 `snack_test/*/result.md`와 집계 스크립트 `src/python/a_log.py`를 기준으로 정리했다. 상품명은 포트폴리오 표에서 A–J로 일반화했다.

## 집계 방법

1. 같은 timestamp에 여러 검출이 있으면 confidence가 가장 높은 class 하나를 선택한다.
2. confidence가 0 이하이고 유효 검출이 없으면 `FAIL`로 기록한다.
3. 선택된 class가 해당 상품의 정답 class와 같으면 correct-class hit로 센다.
4. 비율은 `정답 class 선택 프레임 / 전체 시도 프레임`이다.

따라서 이 값은 mAP, 영상 단위 정확도, 객체별 recall이 아니라 **timestamp 단위 최고 confidence 정답 class 비율**이다.

## 결과

| 익명 상품 | 정답 class 선택 | 전체 시도 | 기록 비율 |
|---|---:|---:|---:|
| Product A | 275 | 305 | 0.90 |
| Product B | 260 | 261 | 0.99 |
| Product C | 280 | 307 | 0.91 |
| Product D | 239 | 317 | 0.75 |
| Product E | 296 | 315 | 0.94 |
| Product F | 263 | 273 | 0.96 |
| Product G | 293 | 306 | 0.96 |
| Product H | 251 | 304 | 0.82 |
| Product I | 230 | 296 | 0.78 |
| Product J | 296 | 297 | 0.99 |
| **합계/가중 집계** | **2,683** | **2,981** | **0.9000** |

상품별 기록 비율의 단순 평균도 0.90이며, 프레임 수로 가중한 전체 비율은 `2,683 / 2,981 = 0.900034...`이다.

## 해석

- 10개 클래스 전체로는 약 0.90의 정답 class 선택 비율을 기록했다.
- Product D와 I가 상대적으로 낮아 클래스별 혼동과 촬영 조건을 별도로 살펴야 한다.
- 전체 수치 하나만으로 안정성을 주장하기보다, 낮은 두 클래스의 false positive와 검출 실패를 나누어 분석하는 것이 다음 단계다.
- 원시 CSV와 학습 이미지는 공개 범위에서 제외했으며, 집계 로직과 최종 class별 요약만 보존했다.
